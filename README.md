# Sito ufficiale di Davide Stocovaz

Sito multipagina dedicato ai libri, alle poesie, ai racconti e alla biografia di Davide Stocovaz.

## Pagine

- Home
- Libri
- Poesie
- Racconti
- Biografia
- Contatti

Il progetto è in fase di costruzione. I contenuti definitivi saranno inseriti insieme all'autore.

## Pubblicazione dei contenuti

Le modifiche salvate dal pannello editoriale restano in bozza e non generano una
pubblicazione di produzione su Netlify. La voce **PUBBLICA TUTTO** raccoglie le
bozze aperte dal pannello, le unisce e avvia un solo aggiornamento del sito.

Se una bozza non può essere unita, la procedura si ferma prima della
pubblicazione finale: le modifiche già raccolte restano nel repository e possono
essere incluse nel tentativo successivo.
